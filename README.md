# Tripleten web_project_homeland

Homeland é uma página sobre a galeria de arte da TripleTen, que reúne histórias de pessoas vindas de diferentes lugares do mundo. A proposta é apresentar suas origens e convidar cada pessoa a compartilhar uma história e uma obra ligada à sua cidade natal.

O projeto foi feito com HTML semântico, para organizar melhor o conteúdo da página, e CSS com media queries, para adaptar o layout a diferentes tamanhos de tela.
